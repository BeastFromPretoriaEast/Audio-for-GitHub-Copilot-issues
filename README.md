# Audio for GitHub Copilot: feedback and issues

**Audio for GitHub Copilot** reads GitHub Copilot's chat replies aloud in VS Code, with each word highlighted as it's spoken.

- **Install it** from the Visual Studio Marketplace: search for **Audio for GitHub Copilot** in VS Code's Extensions view.
- **Report a problem or suggest an idea:** [open an issue](../../issues/new/choose).

This repository is only for feedback. Audio for GitHub Copilot is free to install and use, but it isn't open source; see the
[licence](LICENSE).
